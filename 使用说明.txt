币安 × 比特币 · 黑金鼠标指针

适用：Windows 10 / Windows 11 当前用户。

完整版包含 48 款静态指针：17 个标准系统状态、1 个比特币备选、30 个扩展状态。
每一款都提供 32 / 48 / 64 / 96 / 256 五档尺寸（256 是 Windows 允许的最大指针尺寸）。

安装
1. 先把压缩包完整解压到一个文件夹。
2. 默认双击 install.cmd，使用多尺寸资源，让 Windows 自动选择。
   也可以单独双击 install-32px.cmd、install-48px.cmd、install-64px.cmd、
   install-96px.cmd 或 install-256px.cmd，分别使用对应尺寸的单帧 CUR 文件，
   并把 Windows 指针大小同步设为 32 / 48 / 64 / 96 / 256 px。
   安装成功后立即生效，不需要管理员权限。
3. 若某个已打开的软件仍显示旧指针，重新打开该软件即可。

恢复
双击 restore.cmd，恢复到最近一次安装前的指针，并还原当时的系统指针大小。
重复安装会分别备份；每次恢复只回退一层，不覆盖旧备份，控制台会提示还剩几层。
恢复后保留所有指针文件及备份，不删除文件。

安装位置
%LOCALAPPDATA%\BinanceBitcoinCursors\installs\时间与编号\
每次安装目录中还保留独立的 restore.cmd，可用于恢复。
安装成功后，即使移动原解压目录，指针仍然可用。

系统内切换
打开“鼠标属性”→“指针”，在“方案”中选择：
Binance x Bitcoin - Black Gold
固定尺寸方案会追加 - 32px、- 48px、- 64px、- 96px 或 - 256px。
也可以通过“浏览”手动替换单个指针文件。

尺寸与缩放
cursors 文件夹：多尺寸资源。
sizes\32px、sizes\48px、sizes\64px、sizes\96px、sizes\256px：各自独立的单尺寸资源。
各目录包含 17 个标准系统状态、1 个比特币备选指针及扩展素材。
安装器会复制所选目录下的全部 CUR 文件，系统自动映射其中 17 个标准状态。
备选及扩展图标不会自动创建新的系统指针状态，可在“鼠标属性”中手动选择。
固定尺寸指的是 CUR 文件内的图像尺寸。Windows 会按“设置 → 辅助功能 → 鼠标指针大小”
（注册表 CursorBaseSize）统一缩放所有指针，所以 install-32/48/64/96/256px.cmd 会把该值
一并设为对应 px，切换尺寸才能立刻看出差别；install.cmd 用多尺寸资源，
不会改动这个值。restore.cmd 会把该值还原成安装前的设置。
显示缩放（DPI）会在此基础上继续放大或缩小指针，资源尺寸不等于屏幕上的绝对像素尺寸。
256px 是 CUR 格式与 Windows 指针大小的双重上限（宽高字段单字节、最大滑块档位 256），
无法再做大三倍的 288px；256px 素材由 96px 素材高质量放大生成，边缘会比原生尺寸略软。

关于仍然显示原图标的场景
安装成功时会显示“17/17”，表示 Windows 标准指针设置已完整写入并读回。
如系统仍使用默认方案，可在鼠标属性的“指针”页选择对应尺寸的本主题。
若只有某个软件仍显示旧指针，先重新打开该软件。
拖拽、缩放、抓取、自动滚动等图标经常由应用自己提供。
本包已提供这些扩展 CUR 素材，供支持自定义指针的软件或网页使用；
Windows 的系统方案没有对应的全局映射项，安装器不能强制替换应用内部图标。

只读检查（可选）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -ValidateOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Size 48 -ValidateOnly
检查会确认全部 CUR 文件可加载；固定尺寸还会检查每个文件只有 1 个匹配尺寸的图像帧。
只读检查不安装、不应用、不修改注册表。

安装脚本仅在你运行后修改当前用户的鼠标指针设置。
安装前会校验全部文件并保存原值，运行中失败会尝试自动恢复。
成功前会读回确认全部 17 个系统指针路径，控制台显示 17/17。
其他应用自行绘制的鼠标指针不受系统方案控制。
这是一套独立设计的主题素材，不代表币安或比特币相关机构的官方产品。
